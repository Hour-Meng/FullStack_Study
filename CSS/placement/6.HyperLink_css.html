HyperLink CSS: target Properties Demo

The examples below show how target, target-name, target-new, and target-position are written in CSS. These properties are from an old CSS3 draft and are not supported in modern browsers.

1) target (shorthand)

Shorthand for target-name, target-new, and target-position.

Open using target shorthand (demo)

2) target-name

Specifies the target destination name for the link.

Open using target-name (demo)

3) target-new

Specifies whether to open in a new window or existing context.

Open using target-new (demo)

4) target-position

Specifies where the destination should be placed.

Open using target-position (demo)
